# Google Apps Script Web App 版

このフォルダは、[index.html](../index.html) と同じツールを Google Apps Script の Web App として動かすためのコピーです。

## セットアップ手順

1. Google スプレッドシートを新規作成する(または既存のシートを使う)。
2. メニューの「拡張機能」→「Apps Script」を開く。
3. エディタ左側のファイル一覧で、デフォルトの `Code.gs` の中身をこのフォルダの [Code.gs](Code.gs) の内容に置き換える。
4. 「+」→「HTML」でファイルを追加し、ファイル名を `index` にする(拡張子 `.html` は自動で付くので入力不要)。中身をこのフォルダの [index.html](index.html) の内容で丸ごと置き換える。
5. 右上の「デプロイ」→「新しいデプロイ」→種類の選択で「ウェブアプリ」を選ぶ。
   - 実行するユーザー: 自分
   - アクセスできるユーザー: 用途に応じて選択(チーム内だけなら「全員(Google アカウントが必要)」など)
6. 「デプロイ」を押し、表示されたウェブアプリのURLにアクセスして動作確認する。

## 注意点

- このコピーは `index.html` と**完全に独立**しています。今後 `index.html` 側に機能追加・バグ修正をしても、このフォルダには自動反映されません。Apps Script 側にも同じ変更を入れたい場合は、その都度この `apps-script/index.html` を更新・再デプロイしてください。
- 送信履歴やチーム名・背番号は今まで通りブラウザの localStorage に保存されます。ただし Apps Script の Web App は GitHub Pages 版とは別オリジンで動くため、**履歴やチーム設定は GitHub Pages 版とは共有されません**(それぞれの環境で別々に保存されます)。
- コードを変更するたびに、Apps Script エディタ上の「新しいデプロイ」(または既存デプロイの「編集」→バージョンを更新)をしないと、公開中のURLには反映されません。
